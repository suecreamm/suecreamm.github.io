## Overview

A browser-based tool for generating carbon nanotube structures with customizable geometric parameters.

It supports both **zigzag** and **armchair** CNTs and is intended for quick structure generation before visualization or atomistic calculations.

## Features

- Zigzag and armchair CNT generation
- Adjustable geometric parameters
- Structure visualization
- Export for further computational use
